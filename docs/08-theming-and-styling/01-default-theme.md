# 08-01 — Default Theme

**Source:** `libs/react-material/shell/src/lib/shell.tsx`

## Overview

Code Framez ships with a dark theme built with MUI's `createTheme`. It is applied automatically when no custom theme is provided via `ShellConfig.theme`.

---

## Theme Definition

```typescript
const defaultTheme = createTheme({
  palette: {
    mode: 'dark',
    primary: { main: '#6366f1' },       // Indigo
    secondary: { main: '#ec4899' },     // Pink
    background: {
      default: '#0f172a',              // Slate 900
      paper: '#1e293b',               // Slate 800
    },
  },
  typography: {
    fontFamily: '"Inter", "Roboto", "Helvetica", "Arial", sans-serif',
    fontSize: 13,
  },
  shape: {
    borderRadius: 6,
  },
  components: {
    MuiCssBaseline: {
      styleOverrides: {
        body: { margin: 0, padding: 0, overflow: 'hidden' },
      },
    },
  },
});
```

---

## Color Palette

| Token | Hex | Swatch | Use |
|-------|-----|--------|-----|
| `primary.main` | `#6366f1` | 🟪 Indigo | Buttons, active tabs, toggle highlights |
| `secondary.main` | `#ec4899` | 🩷 Pink | Accents, badges, secondary actions |
| `background.default` | `#0f172a` | ⬛ Slate 900 | Page background |
| `background.paper` | `#1e293b` | 🟫 Slate 800 | Cards, toolbar, tab bar, panels |

### Derived Colors (auto-generated by MUI)

MUI automatically derives `light`, `dark`, and `contrastText` variants:

| Token | Derived |
|-------|---------|
| `primary.light` | Lighter indigo |
| `primary.dark` | Darker indigo |
| `primary.contrastText` | White |
| `text.primary` | White (dark mode) |
| `text.secondary` | Light gray |
| `text.disabled` | Muted gray |
| `divider` | Semi-transparent white |

---

## Typography

| Property | Value |
|----------|-------|
| Font family | `"Inter", "Roboto", "Helvetica", "Arial", sans-serif` |
| Base font size | 13px |

Inter is the preferred font. If not loaded, it falls back through the stack to system sans-serif.

---

## Shape

| Property | Value |
|----------|-------|
| `borderRadius` | 6px |

Applied globally to all MUI components (buttons, cards, menus, etc.).

---

## CssBaseline Overrides

```typescript
body: {
  margin: 0,
  padding: 0,
  overflow: 'hidden',
}
```

- Removes default browser margins
- Hides overflow on the body (the shell manages its own scrolling)

---

## Where the Theme Applies

The `Shell` component wraps everything in `ThemeProvider`:

```tsx
<ThemeProvider theme={config.theme ?? defaultTheme}>
  <CssBaseline />
  <ViewHostProvider ...>
    <ShellLayout ... />
  </ViewHostProvider>
</ThemeProvider>
```

All MUI components inside the shell — tabs, buttons, menus, typography — inherit this theme.
