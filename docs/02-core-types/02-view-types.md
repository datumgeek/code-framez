# 02-02 — View Types

**Source:** `libs/core/types/src/lib/types.ts`

## ViewId

```typescript
type ViewId = string;
```

A UUID string uniquely identifying a view instance. Generated by `uuid.v4()` when `launchView()` is called.

---

## ViewComponentKey

```typescript
type ViewComponentKey = string;
```

A unique string key that identifies a view component type in the registry. Examples: `'welcome-dashboard'`, `'user-list'`, `'user-detail'`.

This key connects:
1. The `ViewComponentRegistration` (metadata) in the store
2. The `ViewComponentMap` entry (actual React component) in the view host provider
3. The `componentKey` property on each `ViewInstance`

---

## ViewLaunchState

```typescript
type ViewLaunchState = 'static' | 'dynamic';
```

| Value | Description |
|-------|-------------|
| `'static'` | Reserved for views that are part of the initial layout (future use) |
| `'dynamic'` | View was created at runtime via `launchView()` |

Currently, all views are created as `'dynamic'` since they are launched through the store.

---

## ViewState

```typescript
type ViewState = 'active' | 'inactive' | 'loading' | 'error';
```

The lifecycle state of a view instance.

| Value | Description |
|-------|-------------|
| `'active'` | View is mounted and functional |
| `'inactive'` | View exists but is not the active tab |
| `'loading'` | View is loading data or initializing |
| `'error'` | View encountered an error |

**Current implementation:** All views are created with `viewState: 'active'`. Components can update their own state via `updateViewState()`.

---

## ViewLaunchConfig

```typescript
interface ViewLaunchConfig {
  componentKey: ViewComponentKey;
  paneType: PaneType;
  displayText: string;
  displayIcon?: string;
  componentProps?: Record<string, unknown>;
  entityType?: string;
  menuText?: string;
  menuOrder?: number;
}
```

The input to `launchView()` — everything needed to create a new view instance.

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `componentKey` | `ViewComponentKey` | Yes | Must match a key in both the component registry and the component map |
| `paneType` | `PaneType` | Yes | Target pane region |
| `displayText` | `string` | Yes | Tab title text |
| `displayIcon` | `string` | No | Icon identifier for the tab |
| `componentProps` | `Record<string, unknown>` | No | Arbitrary props forwarded to the view component |
| `entityType` | `string` | No | Entity type association (for entity-aware views) |
| `menuText` | `string` | No | Override text for entity menu items |
| `menuOrder` | `number` | No | Sort order in entity menus |

### Example

```typescript
launchView({
  componentKey: 'user-detail',
  paneType: 'main',
  displayText: 'Alice Chen',
  componentProps: { userId: '123', userName: 'Alice Chen' },
  entityType: 'user',
});
```

## ViewInstance

```typescript
interface ViewInstance {
  viewId: ViewId;
  componentKey: ViewComponentKey;
  paneType: PaneType;
  displayText: string;
  displayIcon?: string;
  launchState: ViewLaunchState;
  viewState: ViewState;
  componentProps?: Record<string, unknown>;
  entityType?: string;
  entityId?: string;
  createdAt: number;
}
```

A fully resolved view instance living in a pane. Created by `launchView()` and stored in `PaneState.viewInstances`.

| Property | Type | Description |
|----------|------|-------------|
| `viewId` | `ViewId` | UUID generated at launch time |
| `componentKey` | `ViewComponentKey` | Links to the registry and component map |
| `paneType` | `PaneType` | Which pane this view currently lives in |
| `displayText` | `string` | Tab title displayed to the user |
| `displayIcon` | `string \| undefined` | Tab icon |
| `launchState` | `ViewLaunchState` | How the view was created |
| `viewState` | `ViewState` | Current lifecycle state |
| `componentProps` | `Record<string, unknown> \| undefined` | Props passed to the component |
| `entityType` | `string \| undefined` | Associated entity type |
| `entityId` | `string \| undefined` | Associated entity identifier |
| `createdAt` | `number` | Unix timestamp (ms) when the view was created |

## ViewComponentRegistration

```typescript
interface ViewComponentRegistration {
  componentKey: ViewComponentKey;
  displayText: string;
  displayIcon?: string;
  paneType: PaneType;
  launchAtStartup?: boolean;
  entityTypes?: string[];
  entityMenu?: EntityMenuConfig;
  metadata?: Record<string, unknown>;
  order?: number;
  permissions?: string[];
}
```

The registration entry that developers create to declare a view component to the shell.

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `componentKey` | `ViewComponentKey` | Yes | Unique identifier |
| `displayText` | `string` | Yes | Display name in menus and tabs |
| `displayIcon` | `string` | No | Icon identifier |
| `paneType` | `PaneType` | Yes | Default target pane |
| `launchAtStartup` | `boolean` | No | Auto-launch when shell initializes |
| `entityTypes` | `string[]` | No | Entity types this view handles |
| `entityMenu` | `EntityMenuConfig` | No | Context menu configuration |
| `metadata` | `Record<string, unknown>` | No | Arbitrary metadata |
| `order` | `number` | No | Display/sort order (lower = first) |
| `permissions` | `string[]` | No | Required roles to access this view |

### Example Registration Array

```typescript
const views: ViewComponentRegistration[] = [
  {
    componentKey: 'nav-explorer',
    displayText: 'Explorer',
    paneType: 'nav',
    launchAtStartup: true,
    order: 1,
  },
  {
    componentKey: 'user-detail',
    displayText: 'User Detail',
    paneType: 'main',
    entityTypes: ['user'],
    entityMenu: {
      menuText: 'View User Detail',
      menuIcon: '👤',
      order: 1,
      entityTypes: ['user'],
    },
  },
];
```

## EntityMenuConfig

```typescript
interface EntityMenuConfig {
  menuText: string;
  menuIcon?: string;
  order?: number;
  entityTypes: string[];
}
```

Configuration for adding a view to entity context menus.

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `menuText` | `string` | Yes | Text shown in the context menu |
| `menuIcon` | `string` | No | Icon/emoji shown next to the menu text |
| `order` | `number` | No | Sort order (lower values appear first, default: 100) |
| `entityTypes` | `string[]` | Yes | Entity types this menu item applies to |

When a user triggers an entity menu for type `'user'`, the store scans all registrations for ones with `entityMenu.entityTypes` containing `'user'`, sorts by `order`, and returns them as menu items.
